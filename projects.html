Détail des Réalisations

1. Portfolio Personnel

Création d'un portfolio complet conçu dans le cadre de la validation des compétences web. Ce projet intègre une approche écoconception avec une feuille de style optimisée et un JS léger sans dépendance.

Technologies : HTML5 sémantique, CSS3 (Grid/Flexbox), JavaScript Vanilla.

2. Super Application Multiservices

Développement d'une application dynamique permettant de gérer différents modules d'outils du quotidien. Sauvegarde de l'état utilisateur via LocalStorage.

Technologies : JavaScript ES6+, Web Storage API, CSS Grid.

3. Maquette de site E-commerce

Intégration fidèle Pixel-Perfect d'une interface E-commerce. Adaptation fluide pour ordinateurs, tablettes et terminaux mobiles.

Technologies : HTML5, CSS Flexbox, Prototypage Figma.
